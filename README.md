## 🚀 Projects

### 📡 Bluetooth Chat App
> A peer-to-peer chat app over Bluetooth — **zero data stored**. Messages exist only during the session; once the connection drops, everything is gone. Privacy by design, not by policy.

![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=flat&logo=kotlin&logoColor=white)
![Bluetooth](https://img.shields.io/badge/Bluetooth-Classic%20%2B%20BLE-0082FC?style=flat&logo=bluetooth&logoColor=white)
![Architecture](https://img.shields.io/badge/Architecture-MVI-4CAF50?style=flat)
![Storage](https://img.shields.io/badge/Storage-Zero%20Persistence-red?style=flat)

**What makes it interesting:**
- 💬 Real-time messaging over Bluetooth without internet
- 🔒 Ephemeral by design — no logs, no SQLite, no SharedPrefs
- 📴 Works completely offline — no server, no cloud
- 🔗 Handles connection lifecycle, pairing, and device discovery

### 🌤️ Weather App — Retrofit + Koin
> A clean weather app built to practice production-grade networking and dependency injection patterns using Retrofit and Koin.

![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=flat&logo=kotlin&logoColor=white)
![Retrofit](https://img.shields.io/badge/Network-Retrofit2-FF6B35?style=flat)
![Koin](https://img.shields.io/badge/DI-Koin-F5A623?style=flat)
![Architecture](https://img.shields.io/badge/Architecture-MVI-4CAF50?style=flat)

**What's inside:**
- 🌐 REST API calls via **Retrofit2** with clean repository pattern
- 💉 Dependency injection with **Koin** — no boilerplate, lightweight
- 📦 ViewModel + LiveData for lifecycle-aware UI state
- 🗺️ Location-based weather with real API integration

### 🎙️ Echo Journal — Voice Notes with Moods
> A daily journal app where you record voice notes and tag them with custom moods. Your journal entry is your voice — analyzed and categorized by the emotion behind it.

![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=flat&logo=kotlin&logoColor=white)
![Room](https://img.shields.io/badge/DB-Room-3DDC84?style=flat&logo=android&logoColor=white)
![Architecture](https://img.shields.io/badge/Architecture-MVI-4CAF50?style=flat)
![Audio](https://img.shields.io/badge/Audio-MediaRecorder%20%2F%20ExoPlayer-FF5722?style=flat)

**What makes it unique:**
- 🎤 Voice recording as the primary input — no typing required
- 😌 Custom mood tagging system tied to each journal entry
- 📅 Daily journal timeline with mood history
- 💾 All data stored locally with **Room** — your thoughts stay on your device
